# 브레인웍스 홈페이지 완성도 점검 보고서 (2026-09-11)

## 1. 한 줄 총평

공개 웹은 계획한 정보 구조와 디자인 시스템을 대체로 구현했지만, 운영 안정성을 좌우하는 기본기(오류 페이지, SEO 태그 정합성, 보안 헤더, 이미지 용량, 접근성 세부)가 빠져 있었고, 관리자 콘솔은 화면은 갖춰졌으나 실제 운영 흐름에서 데이터가 조용히 유실되거나 버튼이 잠기는 결함이 여러 개 있었습니다. 코드베이스는 린트 규칙이 비어 있는 등 품질 게이트가 형식만 남아 있었습니다. 이번 세션에서 확정 결함 대부분을 29개 과제, 40개 커밋으로 수정했고, 사용자 판단이 필요한 항목은 아래 5절에 모았습니다.

## 6. 남은 기술 부채 (리뷰에서 보류 처리한 항목)

- 관리자 API에 zod 입력 검증이 한 곳도 없음. 서버 입력 타입이 `string | null`을 반영하지 않으나 `request.body`가 `any`라 지금은 무해.
- 뉴스 슬러그 고유 제약 위반 매핑(23505 → 400)에 단위 테스트 없음 (DB 테스트 기반 부재).
- 생성 직후 이동 시 미저장 경고 오탐 방지가 Next 16 라우터 내부의 await 순서에 의존. 코드 주석으로 명시. Next 업그레이드 시 회귀 확인 필요.
- 생성 경로 회귀 테스트가 NoticeForm에만 있음. 나머지 4개 폼은 같은 한 줄 수정이나 미검증.
- `uploadImage`, `showPreview` 핸들러에는 중복 제출 가드 없음 (비파괴적이라 보류).
- `popup-notices/[id]/reorder.ts`는 UI 호출자가 없는 죽은 API.
- DB 상세 뉴스 응답에 `slug` 필드가 없음 (정적 소스와 차이, 기존 결손).
- `forgot-password`의 출처 불일치 안내 분기는 better-auth가 해당 엔드포인트에 Origin 검사를 걸지 않아 실제로는 도달하지 않을 가능성. 무해한 방어 코드로 유지.
- ESLint 경고 22건 잔존 (`react-hooks/set-state-in-effect` 등, 렌더 안전성 관련이라 수동 검토 필요).

## 8. 원본 체크아웃에 대한 주의

- 원본 체크아웃(`redesign/industrial`)에는 사용자가 편집 중인 미커밋 변경 3개 파일(`AGENTS.md`, `IndustrialHero.jsx`, `industrial.css`)이 있습니다. 이번 작업은 이를 건드리지 않기 위해 워크트리에서 진행했습니다.

- `industrial.css`는 사용자 WIP와 이번 브랜치(Task 13, 파일 끝에 초점 규칙 추가)가 둘 다 건드립니다. 병합 시 파일 끝 추가분이라 충돌 가능성은 낮습니다.
- 워크트리는 자체 `node_modules`(실제 설치)를 가집니다. 정션으로 공유하면 Turbopack 빌드가 깨집니다.
