# 로컬 통합 관리자 계정 프로비저닝 설계

## 목적

대표님을 포함한 사람이 로컬 환경에서 관리자 화면을 직접 테스트할 수 있도록, 저장소에 비밀번호를 남기지 않고 단일 통합 관리자 계정을 생성하는 일회성 명령을 제공합니다.

## 범위

- 대상 환경: 현재 개발용 로컬 PostgreSQL 데이터베이스
- 계정 수: 통합 관리자 1개
- 권한: `role=ADMIN`, `accountStatus=ACTIVE`
- 공개 회원가입: 계속 비활성화
- 계정 중복: 같은 이메일이 이미 있으면 비밀번호를 덮어쓰지 않고 명확한 오류로 중단
- 계정 삭제·비활성화 UI: 이번 범위에서 추가하지 않음

## 사용 방식

`npm run admin:provision` 명령을 실행하면 이메일, 표시 이름, 비밀번호를 대화형으로 입력합니다. 비밀번호는 화면에 표시하지 않으며 명령 인자·소스·로그에 기록하지 않습니다.

명령은 현재 `DATABASE_URL`이 가리키는 로컬 DB에만 연결하고, Better Auth가 사용하는 `admin_accounts`와 `auth_accounts`에 필요한 계정·이메일 로그인 자격을 생성합니다. 비밀번호는 Better Auth의 공식 비밀번호 해시 함수를 사용합니다.

생성 후 대표님은 `http://127.0.0.1:3001/admin/auth/sign-in` 또는 실제 개발 서버 주소에서 로그인합니다. 개발 서버 포트는 환경에 따라 다를 수 있습니다.

## 안전장치

- 필수 환경 변수와 이메일 형식을 먼저 검증합니다.
- 비밀번호는 최소 8자 이상이며 입력 중 재확인합니다.
- 동일 이메일 계정이 있으면 변경하지 않고 종료합니다.
- 트랜잭션으로 사용자·로그인 자격을 함께 생성합니다.
- 공개 회원가입이나 운영 DB 계정 생성 경로는 변경하지 않습니다.

## 검증 기준

- 잘못된 입력과 기존 이메일에서 명확히 실패합니다.
- 새 계정 생성 후 `/admin/auth/sign-in` 로그인으로 `/admin`에 접근할 수 있습니다.
- 비로그인 상태에서는 관리자 경로가 로그인 화면으로 이동합니다.
- 기존 인증·정책 테스트와 타입 검사에 영향이 없습니다.
