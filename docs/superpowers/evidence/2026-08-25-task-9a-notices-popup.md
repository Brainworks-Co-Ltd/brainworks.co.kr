# 공지사항과 팝업 공지 운영 흐름 보완 검증

## 범위

2026년 8월 25일 `feat/homepage-redesign` 브랜치에서 공지사항과 팝업 공지의 공개 조회 및 관리자 목록을 보완했습니다. 계정 설정 화면에는 해당 기능이 아직 개발 예정임을 표시했습니다.

## 확인된 변경

- 공지사항 제목 검색은 본문이 아니라 제목만 대상으로 합니다.
- 공지사항 상세는 공개 로케일의 `READY` 첨부파일을 조회하고 제한 시간 다운로드 API 링크를 제공합니다.
- 현재 슬러그만 공개 상세로 조회하도록 조건을 적용했습니다.
- 관리자 공지 목록은 초안, 예약 게시, 게시 중, 게시 중단 및 보관 상태를 함께 확인할 수 있습니다.
- 관리자 팝업 목록은 국문 및 영문 게시 상태를 함께 보여줍니다.
- 팝업 공개 조회는 예약 게시가 시작된 항목을 포함하고, 공개 판정 후 최대 3건만 반환합니다.
- 계정 설정 안내는 `계정 설정 기능은 추후 개발 예정입니다.`로 변경했습니다.

## 검증

- `npm run typecheck` 통과
- `npm run lint` 통과
- 공지사항 게시 정책, 팝업 제외 저장소, 공지사항 및 팝업 DB 계약, 관리자 대시보드 관련 5개 테스트 파일 통과, 8개 테스트 통과
- `npm run build` 통과

## 아직 남은 운영 검증

- 실제 관리자 브라우저에서 새 공지와 팝업을 생성하고 게시하는 E2E 검증
- 실제 객체 저장소에서 첨부파일 서명 URL을 발급하고 다운로드하는 검증
- 팝업 이미지 업로드와 연결된 공지사항 상세 이동의 운영 데이터 검증

따라서 이 문서는 공지사항 및 팝업 공지 전체 완료가 아니라, 현재 구현된 운영 경계와 남은 검증을 구분한 검토 증빙입니다.
